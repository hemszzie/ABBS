# 🎓 ABBS Nexus Community Platform

A MERN Stack based college community platform developed to centralize campus communication, event management, club activities, announcements, house competitions, external opportunities, and team collaboration.

## 📌 Project Overview

ABBS Nexus Community Platform is a web application that connects students and faculty members through a single platform. It simplifies the management of college events, clubs, announcements, houses, external events, and team formation while providing role-based access for different users.

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/abbs-nexus-community-platform.git
```

### Install Backend

```bash
cd server
npm install
```

### Install Frontend

```bash
cd client
npm install
```

### Configure Environment Variables

Create a `.env` file inside the `server` folder.

```
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
PORT=5000
```

### Start Backend

```bash
npm start
```

### Start Frontend

```bash
npm run dev
```
